# tasks/

Task management, roadmap tracking, and backlog grooming.

**Owns:** the active roadmap, sprint/backlog items, reminders, and scheduling.

**`inbox/`** is the default destination for any query Arion cannot route by
keyword. Triage inbox items and either re-route them or file them here.

**TDD contract:** task-processing logic must have a failing test before
implementation (see `tasks.md`).
